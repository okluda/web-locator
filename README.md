# 網頁定位工具 0.18.3

## 快速開始
1. 展開設定區並瞄準 HTTP 或 HTTPS 目標頁面。
2. 建立輸入欄位定位，並選取準星按鈕。
3. 在填彈區配對定位與資料，執行前檢查後使用安全填值。
4. 如需人工操作準星，按「手動板機」，再於原網頁按「啟用鍵盤操作」。
5. 焦點交接成功後，可由使用者自行按 Enter 或 Space。

## 區域
- 操作區：板機、填彈、準星。
- 設定區：瞄準、定位、定位清單，可展開或收合。

## 手動板機
手動板機不會自動點擊或送出。由於 Side Panel 與網頁屬不同焦點上下文，跳轉後需在原網頁按一次「啟用鍵盤操作」，才能可靠地將鍵盤焦點交給準星。原生 button 與 input 按鈕通常支援 Enter 或 Space，自訂按鈕取決於網站本身。

## 安全界線
- 不自動點擊準星或提交表單。
- 不攔截、模擬 Enter 或 Space。
- 不移動或模擬滑鼠游標。
- 不支援密碼、驗證碼、檔案上傳、iframe 或驗證規避。
- 安全填值不再顯示確認視窗，但仍必須先通過執行前檢查。

## 資料保存
- locatorProfiles：定位清單。
- aimProfiles：準星設定。
- ammunitionProfiles：填彈資料與 locatorId 配對。
- locatorTarget：目前瀏覽器工作階段的目標 Tab。
- page key 使用 origin + pathname，查詢字串目前不納入。

## 疑難排解
- 板機停用：先確認目標有效、定位與填彈配對完整，並重新執行前檢查。
- Space 捲動 Side Panel：先在原網頁按「啟用鍵盤操作」，確認焦點已離開 Side Panel。
- 找不到準星：重新測試或重新選取準星。
- 網頁重新整理：重新等待目標變成 active，再執行前檢查。

## 0.18.3 變更
- 操作區順序改為板機、填彈、準星。
- 「跳到準星」更名為「手動板機」並移至板機區。
- 新增網頁端鍵盤焦點交接提示。
- 操作區與設定區增加不同色系外框。
- 移除各功能區長篇說明，保留必要狀態與安全提示。

### 0.18.3 加號按鈕定位
- 定位模式可選取可見、未停用的 `button[type="button"]` 加號按鈕。
- 支援 `mdi-plus`、`fa-plus`、plus、增加、新增或純 `+` 等辨識。
- 填彈配對加號定位後，輸入改為「+ 次數」，限制 0 至 50 的整數。
- 安全執行會依次數逐次點擊，每次間隔 120ms；停止執行會中止剩餘次數。
- 不支援 submit、reset、隱藏、停用、多重匹配或無法辨識的普通按鈕。
